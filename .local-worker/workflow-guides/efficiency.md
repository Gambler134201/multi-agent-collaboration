# Efficiency helpers (delivery packet, acceptance plan, threshold, context, calibration)

`.local-worker/workflow_assist.py` is one read-only CLI entry for the five small aids; it never calls a model, runs a supplied command or records acceptance. After `--wait` the compact dispatch result now also carries `packet`; `--verbose-result` stays the raw long result, `--progress` is still opt-in, and `--wait-task <original-id>` still attaches without dispatching. Use `packet` (or `packet --task <id>`) instead of re-reading task.json/review.json: it separates real identity, execution state, independent acceptance, changed files, executor claims vs independent evidence, failed/unverified criteria and context pointers; missing or corrupt evidence stays unknown/error. Before acceptance, `acceptance-plan --task <id>` (or `--files a.py b.py`) deterministically prints the smallest relevant independent commands from `acceptance_profiles.json`; commands are data and are never executed, unknown scopes fall back conservatively, and worker self-tests stay distinct from reviewer evidence. Before deciding who does the work, `delegate --scoped --understandable --capability-judged --policy-allowed --expected-benefit --ambiguity low` is a planning aid only: trivial work may stay with GPT, ambiguity or architecture/security/authorization/project-isolation work needs a GPT determination first, and it never replaces the existing authorization/candidate/budget/capability gates or changes a model. To resume a stage without the whole chat, `stage-context --task <id>` or `--stage <id> --project <dir>` reads the goal, current stage, readiness, prerequisite handovers, decisions/interfaces, independent evidence and remaining issues; a missing, stale, corrupt or cross-goal handover refuses instead of being summarised away. `calibration --project <dir>` is a read-only view of independently reviewed rework families (sample counts, source, insufficient-sample state, representative task ids); network/resources/budget/cancel/unknown stay out of the quality denominator and main-mind `final_accepted` is never counted as executor success. It writes no preset and reroutes nothing.
