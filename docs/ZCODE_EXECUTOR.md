# ZCode 执行端

首版适配 ZCode Windows 3.16.3（自带 CLI 0.17.0）。使用桌面登录账户的明确原生渠道、模型和思考强度；不使用 API Key，不解密、读取或转存认证文件，不回退到其他模型。首个真实任务使用 Start Plan / GLM-5.3-Flash / max，写出两份 Python 文件、读回并运行测试，原生会话关闭后才发布终态。

## 使用

1. 在工作台的 ZCode 卡片打开“参数设置 → 模型与连接”，填写本机安装目录和本机桥接端口（默认 19765）。
2. 点击“打开 / 连接 ZCode”，连接成功后自动读取模型列表。可勾选“任务启动前自动打开并连接”；默认关闭，只在已授权任务启动前生效，预检和卡片轮询不会启动应用。如果原程序运行时没有桥接参数，等它的任务结束后完全退出，再通过此入口打开；不会杀掉或重启现有实例。之后可在 ZCode 正常工作，同时接收工作台的独立会话任务。
3. 读取原生模型列表，选择明确渠道、模型和思考强度，保存后启用卡片。思考档位来自该模型的原生目录，未手动选档时沿用已保存值或原生首选/已声明最高档。已有排队任务保留原模型与思考强度，桌面或卡片切换不改写旧任务。
4. 主脑通过模型 ID 派发或明确列入自动路由候选。保留既有手动默认模型，不因接入而迁移其他执行端。Start Plan 可手动刷新原生账户套餐额度，按模型、单位和到期时间分别显示；这不是本任务消耗或人民币余额。人民币费用/底层请求次数没有可靠逐请求计量，开启强制金额或次数上限时仍拒绝执行，不把未知显示成零。

## 运行、续接与额度

工具启动时就写入当前任务的进度，运行中可见命令、搜索、读图及文件操作状态；执行终态仍要等工具和原生会话关闭。指定自测命令需要真实哈希、退出码和工具证据；仅看到最终答复不算测试通过。

已正常结束且会话关闭确认的任务可“继续任务（新会话）”。控制器在同项目/同拥有者校验后，携带上一轮请求与答复的有界、脱敏交接，记录父任务与交接哈希，保留原模型、思考强度、权限和文件范围。新任务使用新的原生会话，既不是重发旧请求，也不是原生历史完整复用；实际原生会话复用仍不支持。结果未知、旧保护版本、跨项目、跨拥有者或扩大文件范围均拒绝。现有整改次数、阶段依赖和独立验收规则继续生效。

额度来自原生 `usageStatsService.getEntitlementSnapshot`，鉴权始终由 ZCode 宿主处理。适配器仅保留当前渠道的数字、单位、模型标签与到期时间，不接触 credentialService。刷新失败保留旧快照并报错，超过三分钟标记缓存过期；账户整体额度变化不能归因为单一任务。切换登录账户后应手动刷新。

## 桥接与工具边界

此版通过仅监听本机的 Electron 调试端口调用已安装版本的原生桌面服务；是版本绑定的适配器，不是 ZCode 稳定公共 API。匹配安装主窗口和渠道身份，不能连接任意调试页面。当前只支持唯一主窗口；升级 ZCode 后需要重新核验。调试端口属于本机用户的应用控制接口，不是对不受信本机进程的隔离层，不应转发到网络。

原生服务负责账户鉴权、模型调用及会话生命周期；适配器只操作自己生成的随机会话，不枚举或读取其他聊天。原生内置工具不向这些会话开放，工具白名单只包含工作台的 `modeldesk_zcode` MCP 工具：文件读取、写入、唯一替换、目录浏览、文件/文本搜索、图片读取、公开网页文本读取和前台 PowerShell 7 命令。无需修改安装包。子代理、动态工作流、后台任务及原生历史直接复用未开放；这不是 ZCode 主脑适配。

搜索默认排除记录、认证、Git 与常见依赖目录，并返回结果截断标记。图片以 MCP 图片内容返回，支持 PNG/JPEG/WebP，单文件最多 2 MiB。网页工具仅作公开 HTTP(S) GET，不携带 Cookie/Authorization/代理凭据；固定已检查的公网 IP，逐次校验重定向，拒绝本机、内网、保留地址和非文本资源。不开放电脑控制、任意第三方扩展或发布工具。

文件与命令通过公共记录/原生配置参数保护。项目范围限制显式路径和列明的业务文件；完全访问可以处理必要的项目外普通文件，记录、认证和原生配置仍受保护。只读咨询不开放写入或终端。目录结果过滤受保护条目；拒绝后停止本轮，不能换工具重试。

卡片的权限修改仅用于后续新任务，旧排队任务继续使用原权限快照；连接安装目录或端口改变则明确拒绝旧任务，不暗换宿主。任务前自动连接需同时满足当前开关和本任务创建时的授权，关闭当前开关可阻止后续自动打开；不会给旧任务追授自动启动权限。

这不是 OS 沙箱，任意程序/脚本在运行时计算的目标无法完整静态验证。自动交付统计仅比较声明文件的哈希；不是全盘写入审计。自测通过不等于独立验收；指定命令需要匹配命令哈希、真实退出码和工具证据。回执未知、会话关闭未确认或保护版本变化不授权自动重发。

## 验证范围

临时记录与 mock 覆盖账户/API 互斥、范围/卡片/预算门禁、任务快照、工具保护、未知结果不重发，以及 Codex/DSH 主脑接口。浏览器测试覆盖两种宿主视图中的卡片和设置弹窗。真实账户验收限于下述小型任务，不代表全部内置工具、复杂工程、失败恢复、取消和所有模型均已通过。

体验对齐增加两轮真实任务：首轮搜索、读图、文件与终端闭环独立验收通过（8 个单测及类型边界）；第二轮通过独立新会话交接找回原标记，完成同文件续接（13 个单测、56 个合法组合、23 个非法类型独立通过）。两轮均固定 Start Plan / GLM-5.3-Flash / max，会话关闭后才验收，无重试。原生套餐权益已真实只读获取；网页工具、自动打开和启动前取消主要为隔离 mock/临时进程检查，未据此宣称所有真实异常场景或宿主都已验收。

两主脑共用控制器、执行器、费用未知语义和独立验收。旧的常驻主脑/MCP 进程需要重新连接以加载新增执行端；页面刷新不更新已载入的 Python 模块。没有更改 DSH 插件工具协议或冒充 DSH 原生新任务已实测。
