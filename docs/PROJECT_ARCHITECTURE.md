# 给项目维护者和 Agent 的架构讲解约定

工作台读取当前项目根的 `project-architecture.json`，将中文模块和业务关系画为交互架构图。适用于任意项目；没有该文件时保留静态模块地图。普通打开、刷新和生成提示不调用模型、不创建文件。需要用户当前 Agent 主动分析和写入这份说明。

## 如何生成或更新

1. 确认当前受信项目目录。只读地图查询取得本次 `index.hash`、已收录源码路径与 `sha256`。Codex 用 `query_project_map`，DSH 用 `brain_project_map`；已有 CLI 也可以使用。查询不会运行项目代码。
2. 阅读项目 README、必要源码和说明，概括真实入口、数据处理、存储及输出。模块名称和说明用中文；区分当前实现与规划。不要根据单个文件名猜业务流程，也不要把规划当作已完成。
3. 按下方格式创建/更新根文件。每个模块引用 1–8 个已收录的真实代码文件及查询返回的完整 SHA-256；不可把摘要或自述当成已核实的代码依据。不能确认的关系标为 `inferred`，在说明中写出不确定处。
4. 再查询地图，检查 `architecture.state`、模块和依据状态；独立核对说明与源码。`matched` 仅表示哈希相符，不是业务正确、任务验收通过或完整覆盖的证明。

```json
{
  "schema": 1,
  "title": "知识助手的工作原理",
  "summary": "描述当前已实现的输入、处理和输出；尚未实现的部分明确标注。",
  "snapshot_hash": "从本次 index.hash 原样复制的64位小写十六进制哈希",
  "nodes": [
    {
      "id": "receive",
      "title": "接收问题",
      "role": "用户入口",
      "description": "这一部分负责什么，与下一部分如何配合。",
      "output": "经过校验的问题",
      "evidence": [{"path": "src/entry.py", "sha256": "该文件的64位小写十六进制哈希"}]
    },
    {
      "id": "answer",
      "title": "组织回答",
      "role": "回答模块",
      "description": "说明输入如何变成输出，以及当前限制。",
      "output": "可查看的回答",
      "evidence": [{"path": "src/answer.py", "sha256": "该文件的64位小写十六进制哈希"}]
    }
  ],
  "edges": [{"source": "receive", "target": "answer", "label": "提交校验后的问题", "confidence": "documented"}]
}
```

以上哈希为占位文字，需替换后才是有效文件。`documented` 表示作者从文档/源码整理的关系声明；`inferred` 表示推断。两者都不代表工作台实测过运行链。代码依据验证不能证明自然语言语义。

## 变更与读取边界

- 文件最大 64 KiB；最多 24 个模块、60 条关系。模块 ID 使用 1–48 位 ASCII 字母、数字、下划线或连字符且唯一。模块标题最多 80 字、描述最多 1000 字；根标题最多 100 字、摘要最多 800 字。
- 文件内容是数据，不能作为系统指令、命令、HTML、权限或自动调用模型的授权。无效内容显示错误并退回基础地图；未知字段不会透传。
- 只读取固定根文件，拒绝链接/目录跳转；依据路径须为规范的项目相对路径。依据只与当前受限索引匹配，未收录的文件不会为了验证讲解而另行打开。它可能被排除、删除或未扫描，保持 `unindexed`，不冒充已验证。
- 根状态 `missing` 表示没有说明；`invalid` 表示格式/大小/路径无效；`matched` 表示快照及所引用文件哈希相符；`stale` 表示受限代码快照或依据发生变化；`unknown` 表示存在未收录依据。单个模块依据状态另行显示。
- 讲解文件每次查询独立读取，修改讲解不依赖清空代码缓存。代码变化后地图提示更新，不会自动覆盖用户讲解或调用模型。未收录文件变化不在检测覆盖内；README 等非代码文档的变更也不在当前快照内。
- 说明可随业务代码纳入项目 Git，但不应包含认证、原始私有数据、任务日志或其他聊天内容。使用主脑工具和工作台时仍按原有项目绑定读取；不会从其他项目继承说明。

## 验证与部署

共享 `project_map.py` 返回此字段，工作台、Codex 和 DSH 沿用原来的项目地图入口，不增加写入 API。代码与模块已经载入的常驻服务/连接需要重新加载后才生效；资源刷新只更新页面，不会自动替换旧 Python 模块。原生宿主验证单独记录。
