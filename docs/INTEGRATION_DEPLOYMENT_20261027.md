## 备份与回滚

运行安装的 `.local-worker/backups/integration-acceptance-20261027/` 保留原文件、候选、哈希清单、切换收据、插件旧/新安装审计及验证日志；正式卸载仍使用各自原始安装资料目录。

需要回滚时先结束任务并退出 DSH/旧 MCP，按 0.2.15 原收据卸载；确认效果后再使用本包 deploy.py 的 `--rollback` 恢复六模块与包源码。原 0.2.14 收据已 uninstalled，不能直接当作可重复安装授权：恢复旧包需要在新的资料目录 prepare/check/install，生成新收据。不得手工改旧收据或覆盖同名插件。

若官方 CLI 效果未知，先核对原安装记录，不盲目卸载/重装或关闭桌面进程。回滚不改任务、模型或账户设置。备份工具的 idle 检查会拒绝正在运行的 DSH/MCP；常规上线后只读核验可使用保存的文件哈希，不能把“宿主正在使用”误报成部署失败。
