# 2026-11-03 源码更新与验证范围

本次从公开 main 整理近期产品代码、测试与通用说明。没有带入本机基线分支历史、私人规划、任务原始记录、迁移包或账户配置；也不自动更新现有安装。

## 更新内容

- **有限并发与隔离工作区**：默认并发 1，可明确配置上限；同模型/后端和同桌面账户通道互斥。Git 编辑任务使用独立 worktree，普通用户目录不被自动初始化 Git。
- **可靠收尾与集成**：控制器冻结任务成果，核对会话及进程证据后只释放本任务资源。独立验收的冻结成果进入持久集成队列；联合检查后仍需主脑独立接受。原请求结果未知时只查询，不换编号重发。
- **用户批准计划**：预览具体阶段、模型和联合检查，用户确认该版本后，原责任主脑续接。前置阶段独立接受并有真实交接后，下游才可派发；多个前置成果需先进入既有集成与验收流程。
- **中文可见性**：任务执行/独立验收/集成状态分开显示；任务关系图解释已记录依赖；四执行端“查看诊断”提供就绪原因和建议，不调用模型、不自动改设置。共享行为连接 Codex 与 DSH 两主脑。
- **执行端修复**：ZCode 原生工具及任务版本快照、实例身份三值判断、只关闭目标会话的恢复入口；WorkBuddy 5.9.2/5.9.3 兼容；公共启动等待与 DSH 安装布局修正。DSH 配套源码版本 0.2.19。
- **规则简化**：预期交付清单与实际访问权限分离；普通任务默认 workspace，只有用户明确限定才使用逐文件范围。新任务终端保护只检查可明确识别的直接目标，不再给全文意图扫描追加命令特例；普通工具错误不等于保护拒绝，执行成功不等于独立验收通过。

## 保留的限制与待办

1. 最近真实双分支自动汇合测试有一项因执行端 Git 操作被保护拒绝，自动集成与下游未触发。源码已明确执行端实现/自测/报告、控制器冻结/集成的职责；该说明不能替代真实重验。
2. worktree 仅隔离开发目录，不是操作系统权限边界。DSH/Pi 参数保护、WorkBuddy/ZCode hook 不保证理解任意动态脚本。复杂命令未识别不等于已证明安全；权限沿用户配置，未接线的 junction/方言候选仍不是现网保护。
3. 新规则不追改旧任务权限快照、旧失败或未知结果。恢复资源必须有正面身份证据，不能靠超时、空 PID 或缺字段推断已结束。
4. 账户积分/用量的未知部分不记为零。版本不符、桥接未就绪及预算不允许时明确说明，不静默切换模型或供应商。
5. WorkBuddy 自动初始化、整目标动态唤醒、宿主重启/OS休眠/跨工作区恢复及新增主脑仍有开放项。原生侧栏、首次信号和冷启动需要使用者本机确认。

## 安装与升级

新安装请按 [Agent 指南](AGENT_INSTALL.md) 与 [安装说明](INSTALL.md)。保留用户模型、权限、预算与记录，不从维护者机器搬运认证或运行配置。

现有安装先保存任务、确认后台空闲并保留可回滚备份；不要热替换正在运行的 worker/MCP。DSH 使用匹配完整后台、插件与本机安装计划，按原收据升级并由用户重开；旧常驻 MCP 不保证自动看到新工具。公开源码更新与本机日常版部署是两件事，不能整目录覆盖运行环境。
