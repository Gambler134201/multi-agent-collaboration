## 原生 PowerShell 7 依赖

Codex 和 DSH 的显式启动入口共用 `panel_startup.py` 的轻量就绪、安装身份核对及端到端预算。冷启动脚本用相同 `/api/ready` 契约与跨进程互斥锁；账户、模型和任务聚合不参与新后台的就绪判断。常驻 MCP 需重新连接才能加载代码。增量模拟与无 Codex 环境的临时原生冷启动单独验证，不能据此声称两宿主 GUI 均已点击通过。详见 [启动与诊断](PANEL_STARTUP.md)。
